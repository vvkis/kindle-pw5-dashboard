Kindle Monitor v0.4.0 加入 KOReader 看板插件。电脑和 Kindle 连接同一 Wi-Fi，即可用配对口令通过 HTTP 更新画面。日常推图无需 Jobman、SSH 或 USB 网络。

## 安装与升级

1. **Windows** 下载 `Kindle-Monitor-0.4.0-win-x64.zip`，完整解压后运行 `Kindle Monitor.exe`。升级时，可在启动新版前迁移旧目录的 `Kindle Monitor Data/settings.json`，保留配置和布局。
2. **Kindle** 需已安装 KOReader。解压 `Kindle-Dashboard-Plugin-0.4.0.zip`，通过 USB 磁盘模式把 `dashboard.koplugin` 文件夹复制到 Kindle 的 `koreader/plugins/`。已有插件时覆盖原目录中的文件。安全弹出后重启 KOReader。
3. **配对与推图** 在 KOReader 顶部最右侧菜单打开第一项「看板模式」。电脑端进入「设置 → Kindle 连接」，选择「看板插件 (HTTP)」，填入 Kindle 显示的 IP、端口（默认 `8686`）和 8 位口令。检测连接后点「推送到 Kindle」，也可开启自动推送。长按「看板模式」可查看连接信息。

## 本版更新

- HTTP 推送根据 KOReader 的显示方向和 Kindle 的物理摆放旋转图片，支持设备顶部朝左或朝右的横屏摆法。USB 和 Wi-Fi SSH 仍可选。
- 连接信息显示 Wi-Fi IPv4、端口和配对口令，已推图时可点按连接条隐藏。
- 图片组件支持 PNG、JPG 和 WebP，提供灰阶、纯黑白抖动、缩放与裁剪。保存的构图用于预览、导出和推送。
- 温度趋势同时显示 CPU 实线和 GPU 虚线，以及各自当前温度。采集间隔、自动推送、显示和天气设置集中在「设置」。

两个 ZIP 均提供 SHA‑256 校验文件。详细操作见 [安装与 Wi-Fi 推送指南](https://github.com/vvkis/kindle-pw5-dashboard/blob/v0.4.0/README.md#安装-koreader-插件与-wi-fi-推送)。
