Kindle Monitor v0.4.1 改进了 Kindle 屏幕识别、连接检测和看板编辑。

- HTTP 模式读取 KOReader 的屏幕尺寸、旋转和机型。也可手选机型或输入分辨率。连接状态按当前选中的方式检测。
- 在预览中可为每个组件独立调整字体、粗细和字号。字体从 Windows 本机选择，发布包无需携带字体文件。
- 新增 AI 额度与余额组件，可按平台或账号显示。Grok Bot 支持手动录入周额度和重置时间。

### 安装或升级

1. **Windows** 下载并完整解压 `Kindle-Monitor-0.4.1-win-x64.zip`，运行 `Kindle Monitor.exe`。升级时可在启动新版前把旧版的 `Kindle Monitor Data/settings.json` 复制到新版对应目录。
2. **Kindle** 解压 `Kindle-Dashboard-Plugin-0.4.1.zip`，把 `dashboard.koplugin` 文件夹复制到 Kindle 的 `koreader/plugins/`。已有插件时覆盖同名文件，安全弹出后重启 KOReader。
3. **Wi-Fi 推图** 将电脑和 Kindle 连到同一 Wi-Fi。在 KOReader 右上角菜单打开「看板模式」。电脑端到「设置 → Kindle 连接」选择「看板插件 (HTTP)」，填写 Kindle 显示的 IP、端口和配对口令，再点「推送到 Kindle」。

两个 ZIP 均提供 SHA-256 校验文件。详见 [安装与 Wi-Fi 推送指南](https://github.com/vvkis/kindle-pw5-dashboard/blob/v0.4.1/README.md#安装-koreader-插件与-wi-fi-推送)。
