Kindle Monitor v0.3.1 将 Windows 电脑状态渲染为灰阶看板，并通过 USB 网络或 Wi-Fi SSH 刷新 Kindle。

- CPU 温度一键启用：随包携带官方签名硬件访问组件，管理员授权后自动准备并启动采集，无需手动下载安装 PawnIO。
- 预览区域直接缩放：点击后使用 Ctrl + 滚轮，或上方 − / ＋、适应、100% 控件；放大后仍可编辑小组件。
- 支持独立多行备忘录、墨水屏字体粗细、横竖屏排版与物理摆放方向。
- 支持 USB / Wi-Fi 地址配置、自定义数据推送间隔及每分钟时钟同步。
- 页脚使用通用更新时间，不再显示电脑主机名。
- 移除旧 Python 演示和旧 PowerShell 采集器；精简字体、语言包和未使用界面库。
- 发布 ZIP 不含个人设置、SSH 密钥、传感器日志或 Chromium 缓存。

下载 `Kindle-Monitor-0.3.1-win-x64.zip`，完整解压后运行 `Kindle Monitor.exe`。不要只复制 EXE，也不要将 GitHub 自动提供的 Source code ZIP 当作可运行软件。

需要已越狱并开放 SSH 的 Kindle。首次配置应完成主机指纹确认与公钥登录；程序不会替用户关闭系统安全设置。首次启用 CPU 温度会自动部署 PawnIO 系统驱动；以后重新启动采集器时，Windows 仍可能请求管理员授权。

验证：20 项测试通过；开发版及 Windows 打包版横竖屏、缩放与后台流程冒烟测试通过。CPU 温度及 USB 刷屏已在实机验证，其他硬件型号和网络环境可能不同。
